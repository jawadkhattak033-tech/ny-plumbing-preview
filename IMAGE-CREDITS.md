# Image Credits

The images below are stock photos from [Unsplash](https://unsplash.com). They are free to use commercially under the [Unsplash License](https://unsplash.com/license), which does not require credit. They fill general spots so the preview looks finished, and the client can replace any of them.

These spots still use labeled placeholders and need the client's real photos: owner portrait, team photo, shop front, careers crew, the Our Work gallery (work-01 to work-12), and the homepage "about us" intro photo.

Source files are in `src/assets/photos/`, cropped to the slot sizes (1920 × 1200, or 1920 × 1080 for the two page heroes and 1920 × 1440 for home-commercial). To replace one, drop a new file with the same name in that folder and run `npm run images`. To return a slot to its placeholder, delete its file there.
